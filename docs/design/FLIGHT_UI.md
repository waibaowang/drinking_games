# 飞行棋页面设计

视觉基准见 `flight-ui-approved.png`：明亮蓝天、四色立体十字棋盘、细长飞机与大号蓝色操作按钮。棋盘、机场、飞机、道具均为可交互 SVG；背景不包含游戏元素。

## 文件职责

- `poker-web/src/flight-board.ts`：52 格公共路线、四色机场和每色 6 格终点坐标。
- `FlightPlane.vue`：飞机图形和编号，不参与状态计算。
- `FlightBoard.vue`：实际房间状态、连接和操作；服务器决定骰子和移动结果。
- `FlightDetails.vue`：规则、实时聊天与记录，在桌面侧栏和手机底部抽屉复用。
- `poker-web/src/flight.css`：仅作用于 `.flight-shell`，不改变德州扑克样式。

红、黄、蓝、绿依次占右上、右下、左下、左上机场，终点航道分别从上、右、下、左进入中心。公共索引保持 `(seat * 13 + progress) % 52`。同格飞机错位排列，金色光圈只表示当前玩家可移动的飞机；手机另有至少 44 像素的飞机选择按钮。

1050 像素及以下使用单列棋盘和底部抽屉，更宽时展开右侧栏。遵循系统减少动态效果设置。聊天不持久化；道具只显示神秘礼盒和剩余轮数，不增加道具效果。

## 素材

`poker-web/public/images/flight-sky.png` 使用内置图像生成能力单独生成。提示要求明亮天蓝色背景、边缘蓬松白云、中心留空，不包含文字、飞机、棋盘或按钮。批准图仅用于设计参考，不直接作为游戏页面背景。

## 验证

运行 `pnpm test` 验证坐标；`pnpm build` 包含 Vue/TypeScript 检查与生产构建；项目根目录的 `scripts/verify.ps1` 同时验证后端和前端。实际浏览器验收结果和阶段提交记录见 `docs/IMPLEMENTATION_PROGRESS.md`。
