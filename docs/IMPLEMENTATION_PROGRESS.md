## 第二轮：整体复查（已完成）

- 恢复：`SHUFFLE_PENDING` 重启后先向回桌玩家返回并广播承诺，再调度发牌；发牌和超时数据库失败会重试；调度去重并修复计时器竞争窗口。
- 安全：Flyway V3 增加 `auth_version`。禁用、重新启用、重置密码和角色变化都会永久淘汰旧 HTTP/STOMP 会话；登录成功轮换 Session ID；出站私有消息也过滤失效账号。
- 规则：累计短码 All-in 达到完整加注额时正确重开加注权；平分彩池的奇数筹码从按钮左侧首位赢家开始；恢复快照增加结构和洗牌承诺校验。
- 并发：补充正常操作与超时竞争、重复 `actionId`、恢复等价和版本推进测试。
- 前端：忽略倒退版本；操作长时间未确认会自动拉取；断线时核验登录状态；改善历史加载、移动下注和操作日志显示。
- 运维：备份使用私有临时文件、压缩校验和原子替换；PostgreSQL 验证脚本增加超时和 V1→V3 数据保留检查；镜像健康检查不再依赖缺失工具；上传与回滚文档更安全。

Ponytail 原则的影响：没有引入 Redis、消息队列、微服务、路由库、状态管理库或额外限流依赖；会话失效使用数据库版本号，仍适合当前单机边界。

## 固定边界

- 单服务器、约 20 人、同时 1～3 桌；不为水平扩展设计。
- 聊天不落库；登录会话不跨应用重启，重新登录后可继续恢复牌局。
- 仅虚拟筹码，不支持充值、提现、抽水、现金结算或筹码交易。
